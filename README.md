# AWS VPC & Cloud Infrastructure Lab

### Overview
A hands-on cloud networking project completed for coursework to design, isolate, and secure a custom AWS environment.

### What I Built:
* **Custom VPC Network:** Set up an isolated VPC from scratch with dedicated public and private subnets and routing tables.
* **Security & Firewalls:** Configured Web, ELB, and Database security groups with strict inbound/outbound rules to control traffic.
* **Instance Deployment & Testing:** Launched test EC2 instances and used RDP and command-line ping tests to verify remote connectivity and network isolation.
